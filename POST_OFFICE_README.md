# 🏛️ Stará Pošta Kovalovice - Interactive Post Office

A beautiful, interactive web application that brings to life the charming post office illustration from Kovalovice, Czech Republic. Built with React, TypeScript, Tailwind CSS, and Framer Motion.

## ✨ Features

### Interactive Elements
- **Animated Rose Garlands**: Gently swaying rose garlands adorn the building and fence
- **Interactive Windows**: Hover over the windows to see them light up with a beautiful blue glow
- **Animated Elements**: Dormer windows, entrance, and decorative elements with smooth animations
- **Responsive Design**: Beautiful layout that works on desktop and mobile devices

### Visual Design
- **Authentic Architecture**: Faithfully recreates the traditional Czech post office building
- **Terracotta Roof**: Distinctive orange roof tiles with proper shading
- **Rose Decorations**: Peach-colored roses and green foliage throughout the scene
- **Historical Details**: Post horn symbol and "STARÁ POŠTA" signage
- **Background Elements**: Sky gradient, trees, and landscaping details

### Information Panel
- **Historical Information**: Learn about the post office's history and architecture
- **Services Offered**: Details about postal services available
- **Opening Hours**: Current operating hours
- **Contact Information**: How to reach the post office
- **Fun Facts**: Interesting tidbits about Czech postal traditions

## 🛠️ Technical Stack

- **React 18** with TypeScript
- **Tailwind CSS** for styling
- **Framer Motion** for animations
- **Lucide React** for icons
- **Vite** for fast development and building

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
# Start the development server
npm run dev

# Or run just the client
cd client && npx vite --port 3000
```

### Building
```bash
npm run build
```

## 🎨 Design Details

The application recreates the charming hand-drawn illustration with:

1. **Building Structure**: Single-story building with terracotta roof and cream walls
2. **Windows**: Four arched windows with divided panes that light up on hover
3. **Dormer Windows**: Two small dormer windows on the roof
4. **Main Entrance**: Central arched wooden door with steps
5. **Rose Garlands**: Animated garlands around the entrance and windows
6. **Fence**: Wooden picket fence with rose decorations
7. **Landscaping**: Green shrubs and background trees
8. **Typography**: "STARÁ POŠTA" on the gable and "KOVALOVICE" below

## 🌟 Interactive Features

- **Window Hover Effects**: Windows glow blue when hovered
- **Animated Garlands**: Roses gently sway and move
- **Information Tabs**: Click to learn more about the post office
- **Smooth Animations**: Staggered entrance animations for all elements
- **Responsive Layout**: Adapts to different screen sizes

## 📍 Location

The post office is located in **Kovalovice**, a small village in the South Moravian Region of the Czech Republic. The building features traditional Moravian architecture from the early 20th century.
